# 📈 InvestIQ

InvestIQ is a modern web-based financial analysis platform designed to simplify stock market research and help users make informed investment decisions.

The platform provides real-time Indian stock market data, detailed company fundamentals, interactive historical price charts, stock comparison tools, financial performance analysis, and AI-powered investment insights through a clean and user-friendly interface.

Users can search for stocks, analyze company performance, compare multiple companies, evaluate important financial metrics, and understand market trends from a single dashboard.

## ✨ Key Features

- 📊 Real-time Indian stock market data
- 🔍 Dynamic stock search
- 📈 Detailed stock analysis
- 🤖 AI-powered stock recommendations
- ⚖️ Compare up to three stocks
- 📉 Interactive historical price charts
- 🗓️ 1M, 6M, 1Y, 3Y, and 5Y chart filters
- 💰 Live share-price comparison
- 📋 Company fundamental analysis
- 📊 Dynamic financial comparison charts
- 🏢 Detailed company information
- 📰 Latest stock market news
- 🔐 Secure user authentication
- 📱 Modern and responsive user interface

## 📊 Financial Metrics

The stock comparison module provides analysis of important financial metrics, including:

- P/E Ratio
- Market Capitalization
- Total Revenue
- Return on Equity (ROE)
- Earnings Per Share (EPS)
- Dividend Yield

The comparison charts are generated dynamically using real financial data, making it easier to understand the financial performance of selected companies.

## 🎯 Project Objective

The main objective of InvestIQ is to simplify complex stock market information and provide users with an easy-to-understand platform for stock research and financial analysis.

The application combines market data, company fundamentals, interactive visualizations, stock comparisons, and AI-based insights to support better and more informed investment research.

## ⚠️ Disclaimer

This project is developed for educational and research purposes only. The information and recommendations provided by the platform should not be considered professional financial advice. Users should conduct their own research before making investment decisions.
